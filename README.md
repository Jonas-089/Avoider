# Avoider
This is a little game I wrote when I was just getting started in Java (There are quite a few things that I would do differently today).
Use the arrow keys to move the player and try to avoid the enemies that start spawning over time.

## Play in the browser
You can play it without installing anything: https://jonas-089.github.io/Avoider/

The original Java code runs in the browser with [CheerpJ](https://cheerpj.com). A GitHub Action builds `avoider.jar` on every push to `master` and publishes it together with `web/index.html` to GitHub Pages.
